# Console3D

framework net8.0
<br>
Before running need to be installed one package:
```
dotnet add package Newtonsoft.Json --version 13.0.4
```
After that point u could be run it:
```
dotnet run -p:DefineConstants="DARKMODE"
```
<br>
The project has <code>objects</code> folder for .json files and examples for it.
